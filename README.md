# Blood Magic — Unofficial Port

Выбранный авторский выпуск Blood Magic для Minecraft 1.21.1 / NeoForge: **3.4.0-46-alpha**. В этом репозитории опубликован тот же JAR, который используется в нашей сборке, без локальной пересборки или изменения кода.

Основа — [Blood Magic [Unofficial Port] автора Olexandre](https://www.curseforge.com/minecraft/mc-mods/blood-magic-unofficial-port). Страница автора ссылается на [WayofTime/BloodMagic](https://github.com/WayofTime/BloodMagic); для этой версии существует [ветка 1.21.1](https://github.com/WayofTime/BloodMagic/tree/1.21.1). Оригинал создан WayofTime и соавторами.

Отдельный Git Olexandre на странице выпуска не указан. Ссылки на исходники здесь обозначают авторский проект и его ветку; они не выдаются за подтверждённый исходный снимок именно CurseForge-JAR.

Ниже — отличия используемой современной ветки от старого окружения 1.7.10. Переносы и исправления выполнены авторами Blood Magic/порта; собственных изменений игрового кода Blood Magic у нас нет. Алтари, сигилы и ритуалы из оригинала не считаются нашими добавлениями.

## Для запуска

Minecraft 1.21.1, Java 21, NeoForge 21.1 и Modopedia1.1.5 или новее. В нашей сборке использовался NeoForge 21.1.264. Thaumcraft не является обязательной зависимостью Blood Magic.

Скачайте [релиз 3.4.0-46-alpha](https://github.com/yzs57phbts-web/blood-magic-unofficial-port/releases/tag/1.21.1-v3.4.0-46-alpha), положите JAR в `mods` вместе с Modopedia. Нужна одна версия Blood Magic.

## Пофиксили

- В авторском переносе устранены ошибки старого доступа к ItemStack NBT и обработки исчезающих пустых данных.
- Исправлены упаковка метаданных NeoForge, устаревшие пути рецептов/данных и загрузка сетевых сообщений.

## Адаптировали

- Старое окружение Forge заменено на NeoForge 1.21.1: именованные реестры, современные рецепты и MapCodec.
- Состояние предметов использует Data Components, обмен данными — NeoForge payloads.

## Добавили

- В современном порте есть базовая интеграция Modopedia, запись и рецепт книги. Автор отдельно отмечает, что полная книга ещё не перенесена.

## Изменили

- Эта сборка относится к современной ветке Blood Magic 3.4; автор порта переносил базу 1.20.1. Она не является буквальным восстановлением всего содержимого 1.7.10.
- В руководстве современного порта Patchouli заменён на Modopedia.

## Исходники и проверка

Этот репозиторий хранит описание, происхождение и контрольную сумму выбранного авторского JAR; исходники находятся по ссылке на авторский Git выше. Не включаем неподтверждённый сторонний форк под видом исходников этого файла.
JAR совпадает по SHA256 с установленным. Наши ранее выполненные проверки совместной сборки не означают полного прохождения Blood Magic. При публикации механики мода и файлы игрового профиля не менялись.
